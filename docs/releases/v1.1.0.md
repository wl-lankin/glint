**Glint now speaks German.** / **Glint spricht jetzt Deutsch.**

### New

- **German interface.** Glint follows the system language: on a German Windows or macOS it starts in German, everywhere else in English. Menus, tooltips, the info panel, the shortcuts overview and the About dialog are translated, and numbers and dates use the local format (`3,8 MP`, `1,5 MB`).
- **Language menu.** More > Language switches between English and Deutsch, or back to following the system.

### Neu

- **Deutsche Oberfläche.** Glint folgt der Systemsprache: auf einem deutschen Windows oder macOS startet es auf Deutsch, sonst auf Englisch. Menüs, Tooltips, Infobereich, Tastenkürzel und der Über-Dialog sind übersetzt, Zahlen und Datumsangaben erscheinen im deutschen Format (`3,8 MP`, `1,5 MB`).
- **Sprachmenü.** Mehr > Sprache wechselt zwischen English und Deutsch oder zurück zur Systemsprache.

If you already have Glint 1.0.0, this update installs by itself the next time you close Glint.
Wer Glint 1.0.0 schon nutzt, bekommt dieses Update automatisch beim nächsten Schließen.
